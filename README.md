# Portfólio — Gabriel Wagner

Portfólio pessoal de Gabriel Wagner, desenvolvedor Full Stack com foco em automação e IA.

🔗 [portifoliogabrielwagner.vercel.app](https://portifoliogabrielwagner.vercel.app/)

## Sobre

Site de página única (React + Vite) com apresentação, stack de tecnologias, projetos em destaque (do GitHub e de automações no ActivePieces) e formulário de contato.

## Stack

- React 19 + Vite 7
- SCSS Modules
- Framer Motion
- react-icons

## Rodando localmente

```bash
npm install
npm run dev      # servidor de desenvolvimento
npm run build    # build de produção em dist/
npm run lint     # eslint
```

## Estrutura

```
src/
  components/   # Navbar, Hero, Skills, Projects, Contact, Footer, etc.
  hooks/        # hooks compartilhados (ex.: acessibilidade de modais)
  assets/       # imagens e capas dos projetos
```
